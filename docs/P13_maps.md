# Карты и таблицы прошивки Honda P13 (OKI M66911)

Источник: аннотированный дизассемблер прошивки (собирается обратно в исходный ROM байт-в-байт инструментами [oki66k-tools](https://github.com/icelord75/oki66k-tools)) и сравнение 17 образцов P13. Адреса одинаковы для всех изученных P13-прошивок (USDM, JDM, тюны).

**Уверенность:** ✔ — подтверждено кодом; ~ — вероятно (по входам/выходам и контексту); ? — найдено обращение, назначение не установлено.

## Формулы перевода

> Важно: в первой версии этого описания карты 0x60AA/0x6172 и 0x63F8/0x659C были перепутаны. Трассировка кода показала: **0x60AA/0x6172 — топливо, 0x63F8/0x659C — зажигание**. Ось нагрузки растёт с MAP (столбец 9 ≈ полный газ).

### Зажигание (0x63F8, 0x659C и доп. карты 0x64C0–0x66D2)

- Результат карты → 0x2AA; к нему прибавляются поправки (0x2B4 — со знаком минус, 0x2AC и др.), значение не опускается ниже 0x2B6 (минимальный угол по строке RPM), затем прибавляется компенсация задержки 0x2B7 (таблица 0x5046).
- Подпрограмма 0x46FB раскладывает итог x на зубья коленвала: искра ставится через **2·(256 − x)/256 зуба** после опорного зуба; зуб = 30° (24 зуба на 720°, 6 на цилиндр).
- Отсюда **угол = x · 60/256 ≈ 0.234° на единицу**; x = 255 — опорный зуб, x = 0 — на 60° позже.
- **Ноль шкалы подтверждён:** x = 0 — это ВМТ (опорный зуб за 60° до ВМТ), угол опережения = x · 0.234° до ВМТ. Стробоскоп на ХХ показал 15°; это совпадает с фиксированным углом 15.0° в 0x63F2 и заводской установкой 15° ± 2° из мануала. Другие значения: 10.1° при прокрутке стартером, ~20° на ХХ при разрежении, 29.5° при полном газе на 7500 об/мин.
- Параметр 0x2A9 (таблицы 0x5000 × 0x502C, по оборотам и напряжению) задаёт начало зарядки катушки — вторую точку той же формулы.

### Топливо (0x60AA, 0x6172)

- Результат карты → 0x193 → (построчные множители 0x6923/0x6937 ×/256, 0x6A77/0x6A8B ×/128, предел 0x6921) → 0x183.
- Длительность впрыска 0x150 = 0x183 × доп. карта 0x18F × 0x18A × 0x182 × 0x162 × член по MAP 0x154 (таблица 0x52EF × барокоррекция 0x189 + 0x200) × IAT 0x152 × 0x15E (ECT, таблица 0x522A) × 0x160; к импульсам прибавляется время открытия форсунки 0x142 (таблица 0x52FB) и добавки (ускорительная 0x146/0x140, 0x148).
- **Связь линейная**: +10% к байту карты = +10% длительности (пока остальные множители те же). Доп. топливные карты 0x623A–0x6384 — множители, **128 = ×1.00** (если карта не применяется, код подставляет 0x80).
- **Вывод на форсунки.** Длительность для каждого цилиндра (0x382–0x388 = 0x150 + поправка цилиндра из 0x52DF) пишется в четыре таймера **0x4C, 0x4E, 0x50, 0x52** — по одному на форсунку (код 0x0579–0x0585). Форсунка открывается через порт P1, закрывается по истечении таймера; самотест при старте проверяет, что эти таймеры считают вниз и останавливаются на 0xFFFF.
- **Миллисекунды (принято: кварц 16 МГц).** Таймер оборотов — 16 МГц / 256 = 16 мкс на тик (это следует из оси RPM). Для таймеров форсунок принят **шаг 4 мкс** (16 МГц / 64): тогда время открытия 0x52FB даёт 0.56 мс при ~14 В и 1.9 мс при ~7 В — типично для низкоомных форсунок Honda; шаг 2 мкс (0.28 мс) или 8 мкс (1.1 мс) физически хуже. **Длительность, мс = значение × 0.004.** Это оценка: ни частота кварца, ни делитель таймера не измерены.

## Аппаратная часть

По фотографиям плат 37820-P13-N00, -N50, -A11 и др.:

- **Процессор — OKI M66911**, родственник 66207. Дизассемблер (oki66k-tools, бывший asm662) использует имена регистров и векторов 66207, поэтому часть имён не совпадает с назначением: вектор `int_serial_rx` (0x01EB) на деле обрабатывает датчики коленвала.
- **ПЗУ — OKI M38256AP (32 КБ, масочное).** Суффикс на корпусе совпадает с именем прошивки: A6 → `P13-900_A6.BIN` (= `P13.bin`), E6 → `P13-J51-E6.bin`, C2 — в USDM-блоке A11. В тюнингованных блоках стоит перепрограммируемое ПЗУ (AM27C512 на переходнике, AT29C256).
- **M82C55A-2** — расширитель портов (аналог Intel 8255); это внешний регистр 0xC000, через который код управляет клапаном VTEC и другими выходами.
- **Перемычки RP11/RP12** выбирают МКПП/АКПП → бит 0x220.0 (0 = МКПП, 1 = АКПП) → пары таблиц. На МКПП-плате (по фото платы) впаяны RP11, RP9, RP1, RP16, J8, RP13, RP8, RP7, RP4, RP17; пустые — RP12, RP10, RP2, RP15, J9, RP14, RP3, RP18.
- **Кварц X1 (Kinseki «KSS»).** Маркировка вида «9.6C KSS 2A» / «9.9C KSS 3F» отличается от платы к плате, то есть это код партии, а не частота. Код указывает на тактовую частоту, кратную 62.5 кГц × 2ⁿ: период 180° считается тиками по 16 мкс (RPM = 1 875 000 / x). Принято **16 МГц** (16 МГц / 256 = 62.5 кГц); надёжно проверить можно частотомером.
- **Документация.** Даташита на M66911 в открытом доступе нет. В «1990 OKI Microcontroller Data Book» есть даташит родственного MSM66207 (стр. 384–404): у него предел 10 МГц, а адреса 0x48–0x4E — генераторы скорости последовательного порта. В прошивке P13 по адресам 0x4C/0x4E/0x50/0x52 работают четыре таймера форсунок, то есть набор периферии M66911 шире и карта регистров отличается — имена регистров от 66207 в дизассемблере местами неверны. Проверены также даташит MSM66201/66207 (1998) и руководство пользователя MSM66591/ML66592 (2002), найденные в архиве laboratoryb.org: первый повторяет карту регистров 66207, второй описывает чип на ядре nX-8/500S с другой раскладкой (SBYCON 0x0F, P0 0x10), так что раскладка M66911 выше 0x44 по-прежнему восстанавливается только по коду.

## Константы в коде

Эти значения — операнды команд, а не таблицы; в редакторе они в блоке «Константы».

| Адрес | Что | Сток JDM | Примечание |
|---|---|---|---|
| 0x0C21 | начальный порог возобновления подачи (выс. кулачки) | 250 = 7500 об/мин | менять вместе с 0x540B |
| 0x0C26 | начальный порог отсечки (выс. кулачки) | 244 = 7684 об/мин | мануал H22A2: отсечка 7700. Менять вместе с 0x540F |
| 0x2EA4 | ограничитель скорости: минимальные обороты | 200 ≈ 4500 об/мин | ниже — ограничитель не работает; USDM — 255 (выкл. полностью) |
| 0x2EAC | ограничитель скорости | 180 км/ч | USDM и тюны — 255 (выкл.) |
| 0x35CA | максимальное сырое ECT для VTEC | 0x44 = 68 ≈ 63 °C | 0xFF — проверка выключена (Ab0VE) |

В USDM начальные пороги те же 7500/7684, а таблица 0x540B/0x540F — 224/220 (8370/8522 об/мин); при каком условии ограничитель переходит к табличным значениям, пока не установлено.

## EGR и его отключение

- **Цель.** Код 0x34A1–0x357A считает целевой подъём клапана: карта 11×10 по строке RPM и нагрузке (0x67AE МКПП / 0x6740 АКПП на низких кулачках; 0x688A/0x681C на высоких — в стоке нули), плюс поправка 0x290, умноженная на коэффициент 0x195 (таблица 0x6A46 по ступени резистора АЦП 0x3D6) → **0x294**; флаг «EGR работает» — 0x11B.4. При флаге 0x11E.2 цель берётся из таблицы 0x6A3A по оборотам. Условия работы: прогретый мотор (ECT-байт < 0x46 ≈ 62 °C), MAP и разрежение выше порогов, RPM-байт ниже 0xC5–0xC8 (≈4400 об/мин) и др.
- **Датчик подъёма** — канал 7 АЦП (ADCR7H) → 0x292. Закрытое положение запоминается в 0x293 (ограничено 0x31…0x5C, ≈1.0–1.8 В), фактический подъём 0x291 = 0x292 − 0x293. Единица карт цели — единица АЦП, ≈19.6 мВ.
- **Соленоид** управляется скважностью через таймер TMR3 (0x3B22); при 0x294 = 0 он выключен.
- **Проверки** (0x3A75–0x3AE7): сигнал датчика выше 0xFA при RPM-байте < 0xC0 → неисправность `pr3_X1H.0`; расхождение подъёма с целью больше 6 при цели ≥ 0x18, разрежении ≥ 0x30 и нормальном напряжении дольше 5 тиков → `pr3_X1H.1`. По логике это код 12 (система EGR).
- **Карты есть и в JDM, и в USDM**, в USDM значения больше (максимум 96 против 62).

**Отключение** (редактор: «Быстрые настройки → EGR: отключение») — два патча кода, байты одинаковы во всех 17 изученных прошивках:

| Адрес | Сток | Патч | Действие |
|---|---|---|---|
| 0x34A1 | `DA 1E 09` (JBR 0x11E.2, 0x34AD) | `03 75 35` (J 0x3575) | расчёт цели пропускается: 0x294 = 0, флаг 0x11B.4 = 0 — клапан закрыт, топливо и зажигание как при неработающем EGR |
| 0x3A76 | `EB 11 0E` (JBS 0x211.3, 0x3A87) | `CB 0F 00` (SJ 0x3A87) | пропускается проверка «сигнал датчика подъёма слишком высокий»; проверка расхождения при нулевой цели не выполняется сама |

Патч проверен дизассемблированием; в машине не проверялся.

## Проверка контрольной суммы и её отключение

ЭБУ требует, чтобы сумма всех байт ROM была равна 0 (байт-компенсатор 0x3A). Код 4B выставляется в двух местах:

| Адрес | Когда | Сток | Патч (обход) |
|---|---|---|---|
| 0x09DB | при старте, если нет признака сохранённой памяти (RAM 0x300 ≠ 0x5A или нет флага дежурного питания): после отключения АКБ, разъёма, замены чипа; а также после перезапуска с кодом 4B | `C9 0D` (JEQ 0x09EA) | `CB 0D` (SJ 0x09EA) |
| 0x0D22 | во время работы, каждые 0x200 проходов | `90 9D F1 7F` (LCB A, 0x7FF1) | `03 36 0D 00` (J 0x0D36) |

- Обе проверки пропускаются и при 0x7FF1 = 0, но этот флаг заодно переключает выбор варианта конфигурации на 0x7FF2 (см. 0x7FF0), поэтому для отключения лучше патч кода.
- Распространённый патч `03 36 0D 00` (hondabase) убирает только проверку во время работы. С неверной суммой такая прошивка работает, пока не пропадёт постоянное питание ЭБУ, а после этого останавливается с кодом 4B на проверке при старте.
- В редакторе: «Быстрые настройки → Проверка контрольной суммы (CRC)» ставит или снимает оба патча. Исправление суммы при скачивании работает независимо.

## АКПП

Переключениями, блокировкой гидротрансформатора и kickdown управляет отдельный блок АКПП, а не P13: таблиц переключений в прошивке нет. Связь с АКПП в коде такая:

- **Сигналы A/T FI A/B от блока АКПП** — биты 7 и 6 внешнего входного регистра 0x8000 (код 0x3791–0x37C9, подпрограммы 0x4A72/0x4A75). Каждый бит читается 4 раза; значение принимается, только если отсчёты совпали (0x2BB = 00/55/AA/FF). Текущие состояния — биты 0 и 2 в 0x229, предыдущие — биты 1 и 3.
- **Снижение угла на время переключения** (0x3802–0x3886): по комбинации сигналов в 0x2BA ставится начальный коэффициент (таблица 0x50FA по скорости, фиксированно 0x50 или 0xF4), угол умножается на 0x2BA/256, затем 0x2BA растёт на 0x2BC (таблица 0x5102 или 0x80/0x04) до переполнения, и снижение снимается. Только с АКПП, на прогретом моторе (ECT-байт < 0x2E ≈ 80 °C) и при RPM-байте выше 0x53–0x60.
- **Проверка линий сигналов** (0x3886–0x38C8, только с АКПП и при нормальном напряжении): недопустимые комбинации и переходы → неисправности `pr3_X2.4/.5`, `pr3_DP.4/.5` — вероятно, коды 30/31.
- **Отдельные калибровки для АКПП** по биту 0x220.0: холостой ход, клапан холостого хода, отсечка при торможении, доп. карты топлива и зажигания, EGR (в описании таблиц помечены «— АКПП»).

## Данные из сервисных мануалов

Сервисный мануал Honda Prelude 62SS000 (1992) и дополнения 62SS020–62SS023 (1993–1996; европейские и австралийские версии, данных именно по USDM H22A1 мало):

- угол зажигания на ХХ — **15° ± 2° до ВМТ** (совпадает с 15.0° в 0x63F2);
- отсечка по оборотам: F20A4/F22A — 6600, H23A — 6800, **H22A2 — 7700 об/мин**; отсечка при торможении двигателем — выше 1100 об/мин (1400 М/Т в мануале 1992 года);
- обороты ХХ (с отключённым EACV): H22A1 — 700 ± 50, H22A2 — 790 ± 50; повышенные обороты на холодную — 1400 ± 200;
- давление топлива (вакуумный шланг регулятора снят): H22A1/H22A2 — 245–285 кПа;
- форсунки низкоомные, 1.5–2.5 Ом, с блоком балластных резисторов;
- переключение впускного тракта (Bypass Control): ниже 4600 об/мин для H22A2;
- распиновка ЭБУ: CYL B11/B12, TDC B13/B14, CRANK B15/B16, MAP D17, TPS D11, ECT D13, IAT D15, O2 D14, клапан VTEC A4, датчик давления масла VTEC D6, SCS D4, ELD D10, датчик детонации D3, форсунки A1/A3/A5/A2, зажигание A21.

## Переменные-входы

- **RPMb** — RPM-байт 0x179/0x289 (0→500, 64→1000, 128→2000, 192→4000, 255≈7900 об/мин)
- **ECT** — ECT 0xD9 (температура ОЖ, сырые единицы)
- **IAT** — IAT 0xD8 (температура воздуха, сырые единицы)
- **BARO** — BARO 0xE0 (атм. давление)
- **MAP** — MAP 0xE1/0x178/0x288
- **VSS** — скорость 0xDF, км/ч
- **VBAT** — напряжение 0xDB (вероятно, АКБ)
- **TPS** — TPS 0xE7/0xE8, производная 0xE9
- **ROW** — строка оси RPM (0xEE низк./0xEF выс. кулачки)

Дополнительно: флаг VTEC — бит 1 в 0x21D (дизассемблер местами пишет 0x11D); бит 0x220.0 — коробка: **0 = МКПП, 1 = АКПП** (перемычки RP11/RP12: на МКПП-плате RP11 впаян, RP12 пустой). Только при 1 работают снижение угла на время переключения (0x37CC) и проверка сигналов блока АКПП (0x3886). Бит выбирает в парах таблиц вариант для своей коробки.

Значения в картах — сырые байты. Перевод в мс впрыска и градусы опережения из кода не выведен: топливо дальше умножается на коррекции, угол проходит через коррекции 0x18F/0x193.

## Форматы

| Обозначение | Подпрограмма | Формат |
|---|---|---|
| `v0` | VCAL 0 | пары байт (x, y), x по убыванию; поиск по всей таблице, линейная интерполяция |
| `v2` | VCAL 2 / 0x43EE | 2 пары (x, y) с ограничением по краям |
| `v1` | VCAL 1 | тройки (x, y16), x по убыванию |
| `v3` | VCAL 3 | 2 тройки (x, y16) с ограничением |
| `w16` | 0x4446 | четвёрки (x16, y16) |
| `row` | 0x4523 / 0x48D2 | 20 байт — по одному на строку оси RPM, интерполяция по дробной части строки |
| `grid` | 0x4545 | 2D: строки = обороты, 10 столбцов = нагрузка; интерполяция по обеим осям |
| `w` / `raw` | прямое чтение `LC`/`LCB` | слова / байты |

В записи `x→y` для входа RPM-байт в скобках указаны об/мин.

## Изменения в коде (< 0x5000)

Тюны USDM (P13SKU85005 и др.) меняют 1 байт кода; Ab0VE — около 200 байт (обходы проверок, VTEC без задержек, скорость = 6 км/ч в 0x7C00). Подробно — в разборе патча Ab0VE.

**Ab0VE_P13.bin** — исходный Ab0VE (H22A_P13_FAST-TRACK_TUNE_RACING.bin) с исправленными выбросами топливной карты высоких кулачков 0x6172, строка 4204 об/мин: 0x61CE (нагрузка 31 %) 145 → 128 (как в JDM), 0x61D0 (56 %) 183 → 147 (в Ab0VE это ≈ +30 % к соседним ячейкам); сумма пересчитана байтом 0x3A (FF → 34).

В обращении встречается вариант Ab0VE_P13 с теми же ячейками, но с обходом проверки суммы во время работы (0x0D22: `90 9D F1 7F` → `03 36 0D 00`) и без пересчёта суммы (0x74 при 0x7FF1 = FF). Проверка при старте (0x09DB) в нём не тронута, поэтому после отключения постоянного питания ЭБУ, по коду, остановится с кодом 4B. Лечится исправлением суммы (редактор делает это при скачивании) или отключением обеих проверок.
